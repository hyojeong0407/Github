# PC Power Dashboard

## 실행
```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

단위·시나리오 테스트는 UI와 독립적으로 `python -m pytest`로 실행한다. `python -m compileall -q .`과 설치된 Streamlit `AppTest` smoke도 검증한다. 장시간 개발 서버는 검증에 사용하지 않는다.

## 현재 정책
- 계산 범위는 가정 전체 전력이 아니라 **PC와 모니터 사용으로 증가한 전력량**이다. PC 사용분 kWh를 독립 사용량으로 요금표에 적용하며 금액은 `PC 사용분 기준 예상 증가액`이고 실제 가정 청구액이 아니다.
- 입력 필수값은 PC·모니터 전력, 하루 사용시간, 월간 사용일수, 모니터 수이며 시작·종료 시간과 목적은 선택이다. 기타 장비는 이번 범위에서 계산하지 않는다.
- 전력 출처 우선순위는 `measured` > `manufacturer_estimate` > `user_estimate` > `example`이다. 기본 동작은 `user_estimate`이며 실측값을 임의로 만들지 않는다. 결과와 UI는 source/status를 보존·표시한다.
- 화면 표시 반올림은 kWh 소수 둘째 자리, W 필요 시 소수 둘째 자리, 시간 소수 첫째 자리, 금액 원 단위 정수, 절감률 소수 첫째 자리다. 내부 계산은 표시 전 원시 정밀도를 유지하고, 0원 분모는 계산 불가, 사용량 증가는 증가 상태로 표시한다.
- PC와 모니터의 입력값으로 전체 W, 일일 kWh, 월간 kWh를 계산한다. 계산식은 `power_calculator.py`에만 있다.
- 화면은 학교 원본 스타일을 유지한다. 왼쪽 회색 입력 패널, 헤더·분석 배너, 요구사항의 네 KPI, 요금 안내, 추이 차트, 장비·패턴·시뮬레이션·추천 영역을 표시한다. 사용 패턴, 절감 시뮬레이션, 계산 기준 및 출처는 동일한 여백·색상 체계의 카드 UI로 표시하며 기존 계산 결과를 재사용한다.
- 모든 계산 결과는 사용자 입력 기반 추정값(`user_estimate`)이다. 실측값이나 예시 데이터를 0으로 보정하지 않는다.
- 기본 입력은 일·주·월 추이를 전력 계산 결과에서 균등 분배하여 생성한다. 각 항목은 `user_estimate`와 `균등 분배 추정` 규칙을 함께 표시하며, 실제 측정값으로 가장하지 않는다.
- 사용 패턴에는 입력된 월간 예상 사용량과 하루 평균 시간이 공통 계산 결과로 표시된다. 시작·종료 시간이 없으면 `09:00~17:00`을 예시 규칙으로만 표시하고 `example` 출처를 붙인다. 이전 기간 데이터가 없으면 비교를 계산하지 않는다.
- 공식 대한민국 전기요금 기준은 아직 검증되지 않았다. 기본 화면은 기존 테스트에 있던 예시 기준 `10원/kWh`를 `data/config.py`의 `DEFAULT_TARIFF`로 사용하고 `tariff_status=example`을 유지한다. 따라서 금액은 예시·추정값이며 화면에 실제 청구액이 아님을 표시한다. 공식 기준 또는 요금 설정이 없도록 `unavailable` 기준을 주입하면 금액·절감액·절감률은 계산 불가로 표시된다.
- 기타 장비는 문서의 미확정 정책에 따라 현재 계산·UI에서 임의로 노출하지 않는다.
- 추천은 외부 AI 호출 없이 입력·계산 결과에 근거한 규칙 기반 fallback을 사용하고, 추천별 priority/rank 순으로 표시한다. 추천에는 근거 없는 절감액을 추가하지 않는다.
- 사용시간 시뮬레이션에는 기존 하루 사용시간 기준의 `1시간 줄이기`, `2시간 줄이기`, `절반으로 줄이기` 프리셋을 제공하며 선택값도 기존 시뮬레이션 계산 경로를 사용한다.
- 월간 예상 사용량은 `consumption_stage.py`의 설정 경계로 새싹형 소비 단계를 계산한다. 기본 81.60 kWh는 `🌱 새싹`이며 `🌲 큰 나무`는 사용량이 많은 단계라는 설명을 함께 표시한다.

## 검증 상태
현재 `python -m pytest`는 33개 테스트를 통과하고 `python -m compileall -q .`도 통과한다. Streamlit AppTest로 기본값(PC 300W, 8시간, 30일, 모니터 40W 1대)의 81.60 kWh, 예시 요금 816원, 시뮬레이션 절감액 408원 및 example/실제 청구액 아님 경고를 확인했다. 추가로 사용시간 프리셋 3종·음수 방지, 🌱 새싹 단계, 추천 순위·근거 표시와 프리셋 선택 후 6.00시간 갱신을 확인했다. 일·주·월 기간 선택 연결, 추이 렌더링, 네 KPI, 장비별 분석, 사용 패턴, 시뮬레이션, 추천 근거도 확인했다.

보류/범위 외 사항은 Spec과 일치한다. 대한민국 공식 요금 기준 검증, 실측 데이터 수집·이전 기간 저장, 영속 저장, 기타 장비 계산 정책은 아직 확정하지 않았다. 예시 요금의 출처는 기존 테스트 설정이며 공식 출처로 표시하지 않는다.
